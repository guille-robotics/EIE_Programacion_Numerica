## 📖 Sobre el Repositorio

Bienvenido al repositorio oficial de laboratorios del curso **EIE200 - Programación Numérica**. 

Este espacio está diseñado para almacenar y organizar todo el material práctico de la asignatura. Aquí encontrarás las guías de ejercicios (estructuradas progresivamente desde fundamentos de programación en Python hasta la implementación de métodos numéricos complejos) junto con sus respectivas soluciones propuestas o códigos de referencia.

## 🛠️ Herramientas y Requisitos

Para desarrollar las guías de este curso, se recomienda tener instalado el siguiente entorno de trabajo:

- **Lenguaje:** Python 3.8 o superior.
- **Librerías Base:** `numpy`, `matplotlib`, `math`.
- **Entorno (IDE):** Visual Studio Code, Spyder, o Jupyter Notebook/Google Colab.
